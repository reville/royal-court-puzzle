# Royal Court · 60-Second Puzzle Challenge

A comedic word connection puzzle game where you connect silly clues down the tree or across branches to make the Queen laugh before time expires!

## Play Online

Play live at: **[https://reville.github.io/royal-court-puzzle/](https://reville.github.io/royal-court-puzzle/)**

## Features

- **7 Comedic Boards**:
  1. *Rising council* — The royal alibi
  2. *Two wings* — A very formal bath
  3. *Round table* — The court gets noisy
  4. *Brave knight* — The cowardly hero
  5. *Morning court* — The alarm clock incident
  6. *Midnight raid* — The crumb detective
  7. *Castle choir* — The royal racket
- **60-Second Timer**: Fast-paced, engaging puzzle countdown with visual urgent indicators.
- **Spoiler-Free Share Cards**: Wordle-style canvas generator that creates an adorable graphic of your board layout, showing letter counts, clues, and solved vs. unsolved answers with no spoilers.
- **Responsive Layout**: Designed to look great on desktop and mobile devices.
